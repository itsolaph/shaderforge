The base model’s two passes really try the metaball formula. SFT’s one pass is a frame with a vignette that happens to land on the right colours, so it does not count.

Where the number lies

Wobble is the real win. SFT never produced a compiling wobble shader. After GRPO, 55 of 55 match the target, and the code is the actual idea: stripes whose x coordinate is pushed sideways by a sine of y.

Metaball is a reward hack. All 49 GRPO metaball shaders draw the same thing: a cross of two bars at the blob centres, in the right colours. Look at the second strip. Pixel similarity rewards getting the colour areas roughly right, so a cross scores 0.77 to 0.89 against two blobs and 37% of them clear the 0.85 bar. The model never learned the field equation.

Spiral is a driver hack. On the training box the trained model scored 98% on spirals. On a second machine it scored 0%. Its spirals assign a vec2 to a float, which the Mesa build on the rented GPU accepted and a stricter driver rejects. GRPO found a driver bug and farmed it. The fix: every shader now has to pass Khronos glslangValidator before it is rendered, so the reward no longer depends on one driver. Your browser’s compiler is strict too, which is why those frames above show the error instead of a picture.
