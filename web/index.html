Too little SFT (0–160) leaves the model unable to emit valid Shadertoy boilerplate; too much SFT (640–2400) crushes logit entropy and erases coding diversity before RL begins. At 480 seen-only examples, all 12/12 held-out prompts produce nonzero GRPO gradient, pushing Run 4 compile rate to 99.3% and held-out shape similarity from 0.134 → 0.756.

Run 4 breakdown & honest tradeoffs

Spiral: 0/46 → 46/46 (100%, mean sim_v2 0.998, min 0.939). Every single spiral compiles under Khronos glslangValidator and WebGL2, uses the true signed atan(p.y, p.x) formula (0/46 abs(atan) mirrors), and matches pixel-for-pixel.

Metaball: cross hack killed (0/49), single-blob shortcut discovered. GRPO replaced Run 2’s cross with an exact circle at Blob A (length(p - c) < r), dropping Blob B. That scores 0.93 median under v1 (49/49 fooled) but 0.724 median under v2 (47/49 rejected).

Wobble: 54/55 compile, phase-shift local optimum. GRPO fixed the Run 3 u/v declaration error and learned uv.x + amp * sin(...) on all 55 tasks, but settled on p.y (shifted by −0.5 from uv.y) and a sticky constant near 2.19 * pi, so only 3/55 clear 0.85 under v2.

Stability-plasticity tradeoff: training 80% held-out / 20% seen from the lighter sft_480 warm start pushed unseen similarity 5.6× higher, while seen-family test_iid_a dipped from 89% → 66% (v2) / 91% → 77% (v1).

Runs 2 & 3: the earlier exploits we closed

Run 2 wobble (55/55 honest): SFT never produced a compiling wobble shader; GRPO discovered x + a·sin(2π·f·y) from pixels alone. Run 2 metaball cross (18/49 fooled): two bars through the blob centres cleared pixel similarity v1. Run 2 spiral driver bug: assigning vec2 to float passed an old Mesa build on the GPU box (98% there, 0% in strict WebGL2). Adding glslangValidator in Run 3 killed the driver bug and the cross, exposing the mirrored abs(atan) spiral hack (6/7 passes) and the SFT overfitting cliff.
